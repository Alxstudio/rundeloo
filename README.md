# Rundeloo

AI-powered job search organizer for developers.

Rundeloo turns a scattered job hunt into a connected system. Answer a few
questions and the AI builds your workspace: companies, interviews, contacts,
and study resources, all linked together without manual setup.

## Status

🚧 In development (pre-v1). Target: production release by December 2026.

## Planned features (v1)

- Conversational AI onboarding that generates your workspace
- Company tracker with table and Kanban views
- Interview prep checklists and post-interview logs
- Contacts and study resources per company
- Automatic link suggestions between notes

## Tech stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui + TipTap
- Supabase (PostgreSQL, Auth, pgvector)
- Claude API
- Stripe
- Vercel + Cloudflare
